SQLab · Sistema Educativo Interactivo de Bases de Datos y SQL
Este proyecto es un recurso educativo abierto creado para el curso 4.º B Informática del CPEM N.º 17.
Su propósito es facilitar el aprendizaje de conceptos de bases de datos y SQL mediante un enfoque interactivo y progresivo por niveles.

Características principales:

Aprendizaje progresivo: cada nivel introduce nuevos conceptos y ejercicios, aumentando la complejidad de manera gradual.

Interactividad: los estudiantes practican directamente con actividades que simulan el uso real de SQL.

Accesibilidad: cualquier persona puede descargar, modificar e implementar el sistema en distintos contextos educativos.

Recurso abierto: pensado para docentes, estudiantes y entusiastas de la informática.

Objetivos:

Comprender los fundamentos de la gestión de bases de datos.

Desarrollar habilidades prácticas en SQL.

Promover un aprendizaje activo y colaborativo.

Uso.

Clonar o descargar el repositorio.

Seguir las instrucciones de instalación incluidas en cada nivel.

Explorar los ejercicios y avanzar progresivamente.

Contribuciones

Este proyecto está abierto a mejoras. Se invita a la comunidad a:

Proponer nuevos niveles o actividades.

Adaptar el sistema a diferentes entornos educativos.

Reportar errores o sugerencias mediante issues en GitHub.
