Utilización del recurso

SQLab · Laboratorio de Bases de Datos es un recurso web interactivo para introducirse en SQL mediante una secuencia que combina explicaciones breves, práctica progresiva y retroalimentación inmediata.

Su premisa de trabajo es: “Primero se entiende, después se escribe”. El manual presenta los conceptos fundamentales y los diez niveles permiten ponerlos en práctica escribiendo consultas y observando sus resultados.

02 · Intencionalidad pedagógica y curricular

El propósito principal es que las y los estudiantes se introduzcan en el lenguaje SQL de manera activa, comprendiendo cómo se organiza la información en una base de datos y resolviendo consultas y operaciones sobre ella.

Objetivos de aprendizaje

  • Definir base de datos y SGBD, y reconocer tabla, fila o registro, columna o campo y celda.
  • Explicar el rol de la clave primaria (PRIMARY KEY) como identificador único de cada fila.
  • Diferenciar DDL, DML y DCL, y relacionar cada grupo con sus comandos.
  • Crear y eliminar tablas con CREATE TABLE y DROP TABLE, utilizando restricciones como NOT NULL, DEFAULT y AUTOINCREMENT.
  • Consultar datos con SELECT, filtrar con WHERE, ordenar con ORDER BY y agrupar con GROUP BY.
  • Agregar, modificar y eliminar filas con INSERT, UPDATE y DELETE.
  • Leer e interpretar mensajes de error como parte del proceso de aprendizaje.

Sugerencia de implementación

Se recomienda usar SQLab como introducción al lenguaje SQL, al inicio de la unidad de bases de datos:

  • El manual del laboratorio sirve como fase de inicio.
  • Los niveles de práctica funcionan como fase de desarrollo.
  • Los niveles avanzados y los retos extra pueden funcionar como cierre integrador o como instancia de evaluación formativa.

Como cada nivel se desbloquea al completar el anterior, el recorrido puede hacerse de forma individual, en parejas o como tarea domiciliaria.

03 · ¿Cómo se utiliza?

  1. Leer el manual teórico. Revisar los conceptos de base de datos, clave primaria y los lenguajes DDL, DML y DCL.
  2. Comenzar por el nivel 1. Cada nivel presenta una teoría breve, sintaxis general y una misión con objetivos.
  3. Escribir y ejecutar consultas. Utilizar la consola SQL; también se pueden insertar comandos con los botones de acceso rápido. Ctrl + Enter ejecuta la consulta.
  4. Revisar los resultados. Las respuestas se muestran como tablas y el panel “Base de datos en vivo” refleja los cambios en los datos.
  5. Usar las ayudas cuando sea necesario. Cada nivel incluye pistas, solución y un reto extra que otorga +20 XP.
  6. Avanzar progresivamente. Los niveles se desbloquean al completar el anterior. El recorrido puede realizarse individualmente, en parejas o como tarea domiciliaria.
Importante: el progreso queda guardado en el navegador y equipo utilizados. No se sincroniza automáticamente entre dispositivos. Conviene utilizar siempre el mismo navegador y recordar que cada nivel permite restaurar sus datos.

04 · Requisitos técnicos y accesibilidad

Acceso

Es una aplicación web que requiere únicamente un navegador. No necesita instalación ni un servidor de base de datos propio para realizar las prácticas incluidas.

Tecnologías

El recurso está desarrollado principalmente con HTML, CSS y JavaScript. Para modificar la teoría o los niveles se requieren conocimientos de desarrollo web.

Apoyos para aprender

Los mensajes de error explican qué falló y por qué; cada nivel cuenta con pistas y soluciones como andamiaje. Los botones de inserción rápida reducen la escritura necesaria.

Diseño Universal para el Aprendizaje

Los contenidos y ejemplos son textuales y la consola admite teclado (Ctrl + Enter). Se recomienda verificar el contraste y la compatibilidad con lectores de pantalla según las necesidades del grupo.

Contraste y tema: esta guía incorpora un selector de tema con tres modos —Claro, Oscuro y Alto contraste— que ajusta colores, bordes y fondos para mejorar la legibilidad según las condiciones de luz o las necesidades visuales. En Alto contraste se refuerzan los bordes, se subrayan los enlaces y se invierten los encabezados de tabla para maximizar la distinción figura-fondo. La preferencia se guarda en el navegador y, si no hay una elección previa, se respeta automáticamente la configuración del sistema operativo (prefers-color-scheme).

05 · Orientaciones para adaptar y reutilizar

La licencia CC0 1.0 permite copiar, modificar, distribuir y utilizar el recurso, incluso con fines comerciales, sin necesidad de solicitar permiso ni de atribuir la autoría.

  • Contextualizar los ejemplos: reemplazar la tabla de ejemplo (el curso 4.º B) y las misiones por datos de la propia escuela, el comercio local o proyectos de la orientación.
  • Ajustar el recorrido: asignar solo algunos niveles, o reordenarlos según el avance del curso, y usar los retos extra como actividad optativa.
  • Trabajar en parejas: que un estudiante escriba la consulta y el otro la explique antes de ejecutarla.
  • Profundizar en DCL: completar con una práctica en un servidor real (por ejemplo MySQL o PostgreSQL) donde se pueda usar GRANT y REVOKE.
  • Integrar con otras materias: conectar las consultas con proyectos de programación o de diseño de interfaces.
  • Reutilizar el modelo: al ser CC0, el laboratorio puede copiarse y rediseñarse para otros contenidos (por ejemplo, Python o HTML) o para otros cursos.
  • Apoyar la gamificación: retomar el sistema de XP y niveles como insumo para la evaluación y la devolución a los estudiantes.

06 · Evaluación formativa

Preguntas guía para la conversación en clase

  • ¿Qué diferencia hay entre una fila, una columna y una celda? ¿Para qué sirve la clave primaria?
  • ¿Qué cambia entre un comando DDL y uno DML? ¿Por qué DROP TABLE es más riesgoso que DELETE?
  • ¿Qué consulta escribirías para obtener solo los estudiantes con nota mayor o igual a 6?
  • ¿Qué error te mostró la consola y cómo lo resolviste?
  • ¿Por qué es importante que no cualquier usuario pueda borrar datos (GRANT y REVOKE)?

Criterio En proceso Logrado Destacado
Conceptos básicos Reconoce tabla, fila y columna, pero confunde clave primaria o SGBD. Explica con sus palabras base de datos, SGBD y clave primaria. Relaciona los conceptos con ejemplos propios de su entorno.
DDL, DML y DCL Distingue algunos comandos con ayuda. Clasifica los comandos en DDL, DML o DCL y explica su función. Justifica qué lenguaje conviene usar en cada situación.
Consultas con SELECT Resuelve consultas simples usando la pista. Filtra y ordena con WHERE y ORDER BY de forma autónoma. Combina condiciones (AND, OR) y agrupa con GROUP BY.
Manipulación y definición Ejecuta INSERT, UPDATE o DELETE con errores frecuentes. Usa INSERT, UPDATE, DELETE y CREATE TABLE correctamente. Aplica restricciones (NOT NULL, DEFAULT) y evita errores como un UPDATE sin WHERE.
Lectura de errores y autonomía Se detiene ante un error o recurre enseguida a la solución. Interpreta el mensaje de error y corrige su consulta. Anticipa errores y orienta a sus compañeros.
Progreso en el laboratorio Completa los primeros niveles. Completa los 10 niveles. Completa los niveles y los retos extra.

La evaluación puede considerar la comprensión de conceptos, la resolución autónoma de consultas, la interpretación de errores, el progreso en los niveles y la capacidad de explicar las decisiones tomadas.
